# WorkFlow Insight

WorkFlow Insight는 가상의 업무 요청 데이터를 분석하는 Streamlit 대시보드입니다. 전체 완료율만으로 파악하기 어려운 부서별 업무 집중과 지연을 살펴보고, 어느 부서의 어떤 업무부터 확인할지 판단할 수 있도록 돕습니다.

## 주요 기능

- 내장 예시 선택, CSV 업로드, 필수 컬럼·상태·날짜 검증
- 담당 부서·업무 상태 필터 및 분석 기준일 선택
- 전체 업무 수, 완료율, 평균 처리 기간, 현재 지연 건수와 비율 표시
- 부서별 업무량과 상태 구성, 현재 지연율과 완료 지연율 비교
- 월별 요청량·완료량, 평균 처리 기간, 완료 지연율 시각화
- 집계 결과를 활용한 규칙 기반 인사이트와 현재 지연 업무 목록

## 데이터 구성과 분석 기준

기본 예시는 가상 업무 9건입니다. 상반기 합성 CSV는 **2026년 1월부터 6월까지** 접수된 가상 업무 660건과 담당 부서 6곳을 포함합니다. 두 파일 모두 이 프로젝트를 위해 만든 데이터입니다.

입력 CSV는 UTF-8이며 첫 줄에 다음 컬럼을 사용합니다.

```text
request_id,department,title,status,requested_at,due_at,completed_at
```

`department`는 업무를 처리하는 담당 부서입니다. 상태는 `대기`, `진행 중`, `완료` 중 하나이고, 날짜 형식은 `YYYY-MM-DD`입니다. `completed_at`은 필수 헤더이며, 실제 날짜 값은 완료된 업무에만 입력합니다.

- **현재 지연**은 마감일이 분석 기준일보다 앞선 미완료 업무입니다. 화면에서는 현재 지연 건수를 전체 미완료 업무로 나눈 비율과 전체 업무로 나눈 비중을 함께 표시합니다.
- **완료 지연**은 마감일 이후에 완료된 업무입니다. 완료 지연율의 분모는 전체 완료 업무입니다.
- 월별 요청량은 요청일, 월별 완료량·평균 처리 기간·완료 지연율은 완료일을 기준으로 집계합니다. 처리 기간은 완료일에서 요청일을 뺀 달력 일수입니다. 분모가 0인 비율은 `—`로 표시합니다.

상반기 합성 CSV의 기본 분석 기준일은 **2026-06-30**입니다. 기본 예시와 직접 업로드한 CSV는 한국 시간 기준 오늘을 기본값으로 사용합니다.

## 기술 스택

| 기술 | 역할 |
| --- | --- |
| Python | CSV 읽기와 검증, 날짜 비교, 규칙 기반 인사이트 |
| Pandas | 날짜 변환, 필터링, 부서별·월별 집계 |
| Streamlit | 프로젝트 개요, CSV 업로드, 필터와 대시보드 화면 |
| Plotly | 차트 시각화와 상세 툴팁 |

## Windows에서 설치 및 실행

Windows와 Python 3.13.5에서 실행을 확인했습니다. 프로젝트 폴더에서 PowerShell을 열고 아래 명령을 실행합니다. `.venv`가 이미 있으면 첫 줄은 생략할 수 있습니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

`python`이 Windows 앱 실행 별칭으로 연결되면, 첫 명령에서 `python` 대신 설치된 Python 실행 파일의 전체 경로를 사용합니다. 공백이 있는 경로는 PowerShell의 호출 연산자 `&`와 따옴표로 실행할 수 있습니다.

브라우저에서 터미널에 표시된 로컬 주소를 열고, 프로젝트 개요의 **분석 대시보드 열기**를 누르면 상반기 합성 CSV를 바로 분석할 수 있습니다.

## 합성 데이터 재생성

재생성 스크립트는 Python 표준 라이브러리와 고정 난수 시드 `20260630`을 사용합니다. 프로젝트 폴더에서 다음 명령을 실행하면 별도 파일에 결과를 저장할 수 있습니다.

```powershell
.\.venv\Scripts\python.exe scripts\generate_synthetic_requests.py --output .\synthetic_requests_preview.csv
```

`--output`을 생략하면 `data/synthetic_requests_2026_h1.csv`에 저장하며 기존 파일을 덮어씁니다. 생성 규칙과 실제 집계 결과는 [합성 데이터 설명서](data/synthetic_requests_2026_h1.md)에 있습니다.

## 데이터 한계 및 유의사항

- 상반기 합성 CSV는 **2026-06-30 상태 스냅샷**입니다. 이후 기준일의 지연 수치는 당시 미완료 기록을 대상으로 마감 경과 여부를 다시 계산한 결과입니다.
- 상태 변경 이력이 없으므로 과거 시점의 미완료 잔량이나 월별 백로그를 추정할 수 없습니다.
- 부서별·월별 차이는 가상 업무 기록에서 관찰한 결과입니다. 지연율 차이만으로 원인이나 업무 성과를 판단하기는 어렵습니다.
