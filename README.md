# WorkFlow Insight

WorkFlow Insight는 **660건의 합성 업무 데이터**로 담당 부서별 업무량과 마감 지연을 비교하고, 월별 업무 흐름을 살펴보는 Streamlit 대시보드입니다. 전체 완료율만으로는 파악하기 어려운 업무 집중과 지연을 확인해 어느 부서의 어떤 업무부터 살펴볼지 판단하는 것이 목적입니다.

## 대표 KPI와 핵심 분석 인사이트

상반기 합성 CSV 전체 부서·전체 상태를 **2026.06.30** 기준으로 분석한 결과입니다.

| 지표 | 결과 | 근거 |
| --- | ---: | --- |
| 전체 업무 수 | 660건 | 전체 합성 업무 |
| 완료율 | 80.0% | 528 / 660건 |
| 평균 처리 기간 | 7.5일 | 완료 528건 기준 |
| 미완료 업무 중 현재 지연율 | 63.6% | 84 / 132건 |
| 전체 업무 중 현재 지연 비중 | 12.7% | 84 / 660건 |
| 완료 업무 중 완료 지연율 | 19.9% | 105 / 528건 |

- **현재 지연 건수가 같아도 지연율은 다릅니다.** 운영팀과 시스템팀의 현재 지연은 각각 22건입니다. 미완료 업무가 운영팀 35건, 시스템팀 30건이어서 현재 지연율은 각각 **62.9%**, **73.3%였습니다.**
- **5월에서 6월 사이 요청량이 120건에서 150건으로 증가했습니다.** 요청일 기준 30건(+25.0%) 증가했습니다. 같은 기간 완료일 기준 완료량은 92건에서 93건, 완료 업무의 평균 처리 기간은 8.0일에서 9.1일로 바뀌었습니다.

## 데이터 출처와 구성

상반기 데이터는 [생성 스크립트](scripts/generate_synthetic_requests.py)로 만든 **합성 업무 데이터 660건**입니다. 고정 난수 시드 `20260630`과 월별·부서별 배정 규칙을 사용했습니다.

- **분석 기간** · 요청일 기준 2026.01.01~2026.06.30
- **상태 스냅샷 및 기본 분석 기준일** · 2026.06.30
- **담당 부서** · 6곳
- **업무 상태** · 완료 528건, 진행 중 79건, 대기 53건
- **기본 예시** · 별도로 만든 가상 업무 9건

두 CSV 모두 프로젝트용 가상 데이터입니다. 생성 규칙과 집계 결과는 [합성 데이터 설명서](data/synthetic_requests_2026_h1.md)에 있습니다.

입력 CSV는 UTF-8이며 첫 줄에 다음 컬럼을 사용합니다.

```text
request_id,department,title,status,requested_at,due_at,completed_at
```

`department`는 업무를 처리하는 담당 부서입니다. 상태는 `대기`, `진행 중`, `완료` 중 하나이고, 날짜 형식은 `YYYY-MM-DD`입니다. `completed_at`은 필수 헤더이며, 실제 날짜 값은 완료된 업무에만 입력합니다.

## 분석 지표 및 계산 기준

| 지표 | 계산 기준 |
| --- | --- |
| 완료율 | 완료 업무 수 ÷ 전체 업무 수 × 100 |
| 평균 처리 기간 | 완료 업무의 `완료일 - 요청일`을 달력 일수로 계산한 평균 |
| 미완료 업무 중 현재 지연율 | 현재 지연 업무 수 ÷ 미완료 업무 수 × 100 |
| 전체 업무 중 현재 지연 비중 | 현재 지연 업무 수 ÷ 전체 업무 수 × 100 |
| 완료 업무 중 완료 지연율 | 마감일 이후 완료된 업무 수 ÷ 완료 업무 수 × 100 |

- 현재 지연은 마감일이 분석 기준일보다 앞선 **대기·진행 중** 업무입니다. 완료 지연은 완료일이 마감일보다 늦은 **완료** 업무입니다.
- 월별 요청량은 요청일, 월별 완료량·평균 처리 기간·완료 지연율은 완료일을 기준으로 집계합니다. 분모가 0인 비율은 `—`로 표시합니다.
- 내장 상반기 합성 CSV의 기본 분석 기준일은 **2026-06-30**입니다. 기본 예시와 직접 업로드한 CSV는 한국 시간 기준 오늘을 기본값으로 사용합니다.

## 주요 기능과 기술 스택

- 내장 예시 선택, CSV 업로드, 필수 컬럼·상태·날짜 검증
- 담당 부서·업무 상태 필터 및 분석 기준일 선택
- 전체 업무 수, 완료율, 평균 처리 기간, 현재 지연 건수와 비율 표시
- 부서별 업무량과 상태 구성, 현재 지연율과 완료 지연율 비교
- 월별 요청량·완료량, 평균 처리 기간, 완료 지연율 시각화
- 집계 결과를 활용한 규칙 기반 인사이트와 현재 지연 업무 목록

| 기술 | 역할 |
| --- | --- |
| Python | CSV 읽기와 검증, 날짜 비교, 규칙 기반 인사이트 |

## 실행 방법 및 분석 결과 재현

### Windows에서 설치 및 실행

Windows와 Python 3.13.5에서 실행을 확인했습니다. 프로젝트 폴더에서 PowerShell을 열고 아래 명령을 실행합니다. `.venv`가 이미 있으면 첫 줄은 생략할 수 있습니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m streamlit run app.py
```

`python`이 Windows 앱 실행 별칭으로 연결되면, 첫 명령에서 `python` 대신 설치된 Python 실행 파일의 전체 경로를 사용합니다. 공백이 있는 경로는 PowerShell의 호출 연산자 `&`와 따옴표로 실행할 수 있습니다.

### 대표 결과 재현

1. 브라우저에서 터미널에 표시된 로컬 주소를 엽니다.
2. 프로젝트 개요에서 **분석 대시보드 열기**를 누르면 내장 **2026년 상반기 합성 CSV**가 선택됩니다.
3. 담당 부서·업무 상태 필터를 비워 전체 데이터를 포함하고, 분석 기준일이 **2026-06-30**인지 확인합니다.

### 합성 데이터 재생성

재생성 스크립트는 Python 표준 라이브러리와 고정 난수 시드 `20260630`을 사용합니다. 프로젝트 폴더에서 다음 명령을 실행하면 별도 파일에 결과를 저장할 수 있습니다.

```powershell
.\.venv\Scripts\python.exe scripts\generate_synthetic_requests.py --output .\synthetic_requests_preview.csv
```

`--output`을 생략하면 `data/synthetic_requests_2026_h1.csv`에 저장하며 기존 파일을 덮어씁니다.

## 데이터 한계와 개선 방향

- 상반기 합성 CSV는 **2026-06-30 상태 스냅샷**입니다. 이후 기준일의 지연 수치는 당시 미완료 기록을 대상으로 마감 경과 여부를 다시 계산한 결과입니다.
- 상태 변경 이력이 없으므로 과거 시점의 미완료 잔량이나 월별 백로그를 추정할 수 없습니다.
- 부서별·월별 차이는 가상 업무 기록에서 관찰한 결과입니다. 지연율 차이만으로 원인이나 업무 성과를 판단하기는 어렵습니다.

이후에는 상태 변경 이력을 추가해 월말 백로그를 계산하고, 업무 유형과 난이도 정보를 포함해 지연 패턴을 더 세분화할 수 있습니다.
